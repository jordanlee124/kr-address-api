---
title: Search Addresses
api: GET /v1/search
description: Returns multiple matching addresses for a query
---

Use this endpoint to show users a list of address suggestions (e.g. an autocomplete dropdown). Results are cached for 1 hour.

<ParamField query="q" type="string" required>
  Korean address search query.
</ParamField>

<ParamField query="limit" type="integer" default="5">
  Maximum number of results to return. Range: 1–10.
</ParamField>

<ResponseField name="query" type="string">
  The original query string.
</ResponseField>

<ResponseField name="count" type="integer">
  Number of results returned.
</ResponseField>

<ResponseField name="results" type="array">
  Array of `AddressResult` objects. See [Normalize](/docs/api-reference/normalize) for the full schema.
</ResponseField>

<ResponseField name="cached" type="boolean">
  `true` if served from cache.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://kr-address-api.jordanlee124.workers.dev/v1/search?q=%EA%B0%95%EB%82%A8%EA%B5%AC+%ED%85%8C%ED%97%A4%EB%9E%80%EB%A1%9C&limit=3" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript JavaScript
const r = await fetch(
  'https://kr-address-api.jordanlee124.workers.dev/v1/search?q=' +
  encodeURIComponent('강남구 테헤란로') + '&limit=3',
  { headers: { 'X-API-Key': 'YOUR_API_KEY' } }
)
const { results } = await r.json()
```
</RequestExample>
